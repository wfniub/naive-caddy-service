## 🌟 核心特性

- **双架构部署模式**：
  - **模式 1 (全托管模式)**：独占 80/443 端口，由 Caddy 全自动申请并续签 SSL 证书，原生支持 HTTP/3 (QUIC)。
  - **模式 2 (高位端口直通模式)**：自定义高位端口（默认 `20443`），Docker 直出公网，与现有建站软件（宝塔 / Nginx）完全独立互不影响。
- **灵活证书管理**：
  - 原生 ACME 自动申请；
  - 支持 Cloudflare DNS-01 API 自动签发与无感续签（无需 80/443 端口）；
  - 智能探测并复用本地已有证书（如宝塔已有证书）。
- **抗主动探测机制 (Probe Resistance)**：
  - 内置极简企业边缘网关伪装站；
  - 支持反代本机 80 端口真实网站，探针扫描无任何特征暴露。
- **全平台一键导入**：
  - 自动生成专属导入链接及本地离线黑白二维码；
  - 终端直接扫码，无需任何外部第三方接口中转，确保凭据安全。
- **在线账号管理与版本检测**：
  - 支持多用户凭据增、删、改、查；
  - 支持在线检测 GitHub Release 与一键平滑升级；
  - 内存级热重载（`caddy reload`），配置变更不断流。

## 🚀 快速开始

在 Linux 服务器（Ubuntu / Debian / CentOS / AlmaLinux / RockyLinux 等）上以 `root` 用户运行以下命令：

```bash
curl -fsSL https://raw.githubusercontent.com/wfniub/naive-caddy-service/main/naive-manager.sh -o naive-manager.sh && chmod +x naive-manager.sh && ./naive-manager.sh
```

---

## 🛠️ 管理与日常维护

再次执行脚本即可打开控制面板：

```bash
./naive-manager.sh
```

- **选项 1**：安装 / 重新配置节点服务
- **选项 2**：用户账号管理（添加、删除用户，修改密码，导出链接与二维码）
- **选项 3**：查看实时连接与访问日志
- **选项 4**：重启服务容器
- **选项 5**：平滑热重载配置与证书（无感平滑，长连接不断）
- **选项 6**：一键升级底层镜像（保持数据和证书不变）
- **选项 7**：彻底卸载与清理
